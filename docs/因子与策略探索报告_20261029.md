# 因子与策略探索报告（2026-10-29）

本报告基于项目现有归档研究结果整理，未新增前端页面，也没有把单一发现区间的高收益直接当成稳定策略。

## 研究口径

因子有效候选同时满足：

- 绝对平均 Rank IC ≥ 0.05；
- 绝对 ICIR ≥ 0.35；
- 日度方向命中率 ≥ 64%；
- 有效覆盖天数 ≥ 1300 天。

策略稳定候选同时满足：

- 2023-01-01—2024-12-31 与 2025-01-01—2025-12-31 两个时间隔离验证窗口均有记录；
- 基础成本和压力成本两种口径下，两个窗口的年化收益均 ≥ 10%；
- 两种成本口径、两个窗口的最大回撤均不低于 -20%；
- 使用平台已有 T+1、开盘成交、成本、择时和统一组合账本。

“稳定”是本报告的筛选定义，不代表未来收益保证；这些候选仍属于研究结果，不能直接视为投资建议。历史估值路线还受本地估值覆盖范围约束，换手率结论不外推到 2019 年以前。

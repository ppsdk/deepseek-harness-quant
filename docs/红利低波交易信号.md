# 红利低波交易信号 v1

目标是输出可解释的“低位反转入场、上涨转弱退出”条件，同时区分信号、模拟持仓和实际成交。当前是实验性信号服务；未通过全新样本外验证，不承诺每轮低买高卖或达到特定收益。

## 使用方式

命令行和 HTTP API 使用同一后端。没有另建页面或第二套推荐算法。

```powershell
python -X utf8 scripts/dividend_signals.py --code 512890.SH
python -X utf8 scripts/dividend_signals.py --all --end 2026-10-29
python -X utf8 scripts/dividend_signals.py --code 515450.SH --profile kdj_21_5_filtered
python -X utf8 scripts/render_dividend_signals.py --code 512890.SH
python -X utf8 scripts/render_dividend_signals.py --code 512890.SH --profile kdj_21_5_dmi_ma60 --end 2026-10-29 --compare-profile kdj_21_5
python -X utf8 scripts/render_dividend_signals.py --code 512890.SH --profile kdj_21_5_regime --end 2026-10-29 --compare-profile kdj_21_5
python -X utf8 scripts/compare_dividend_signals.py --end 2026-10-29
```

本地 API：`GET /api/studio/signals/dividend?code=512890.SH&profile=kdj_21_5_regime&end=2026-10-29&history=true`。

`code`、`profile`、`start`、`end`、`history` 为可用参数，未知参数报错，不静默忽略。日期结束不能晚于本机上海时区最近已收盘日期；日期省略时读取现有缓存到该日期，**不使用旧研究配置中的固定结束日假装当前数据**。不自动下载、不下单、不注册定时任务。

配置源是 `config/dividend_signals.yaml.example`；需要自定义时复制为被 Git 忽略的同名 `.yaml`。证券名称和资产基础信息复用 `dividend_timing_research`，观察范围、指标参数、状态名称由配置提供。可将已有基础资产配置中的长江电力等加入观察范围；新的资产还需基础资产配置、未复权行情和公司行为数据。

完整研究结果保存在配置的 `output_dir`，默认 `output/strategy_research/dividend_signals_v1/`。文件名包含证券、参数及输入哈希和请求日期，原始行情、完整账本和图形不提交 GitHub。

## 当前配置与规则

2026-11-02 按用户“KDJ只考虑买入”及图示“低位准备后等转多、弱反弹需要退出”的要求，模板默认配置改为 **`kdj_21_5_regime`**。这是开发中的规则迁移，不是收益选优或正式策略推荐。已有本地 `.yaml` 不自动覆盖；如需迁移，增加模板中的新profile并显式修改 `default_profile`，或通过 `--profile` 指定。旧配置名、参数、算法和历史账本计算含义继续保留。

新默认规则由 `backtest/research_kdj_regime.py` 复用既有KDJ/DMI适配器生成，不维护第二套持仓或成交：

- **低位准备**：KDJ(21,5,5)，近30个观察交易日出现过K、D同时≤20，以及K上穿D；当前K>D且收盘高于昨日。把准备和金叉窗口从旧版5/3日扩到30/30日，使确认前的准备条件可以保留；窗口到期自然失效，并不把低位日期倒写成买点。
- **转多确认后买入**：上述条件成立后，还需连续3日 `+DI > -DI`、收盘高于MA10，且MA10高于3日前。ADX在空头趋势消退时可以下降，入场没有隐含“ADX必须上升”的要求。仅两天的转多不足以买入。
- **多头衰减退出**：此前10日内曾同时 `+DI > -DI`、+DI≥25、ADX≥25；随后连续2日+DI下降、ADX下降、-DI上升。无需等DI交叉，也无需同时跌破MA60。
- **弱趋势/反弹失败退出**：连续3日 `-DI > +DI`，且连续2日满足“上述偏空确认仍成立、收盘低于MA20、MA20低于3日前”。不需要此前存在高ADX强多头，从而补齐弱反弹和入场失败的退出。
- 两种退出满足任一种即可；KDJ完全不参与退出。空仓时满足退出条件只显示等待，不伪装成已卖出。现有风险、费用、T+1执行口径继续由统一模拟器处理。

这些周期和阈值是图示反馈后的可配置工作定义，不能由截图直接读出，也未证明最优。图示区间属于开发样本，不能再称全新样本外验证。未用标注日期硬编码委托，也未扫描参数以逐点重合红线。

512890实际回放中，2025-12不再提前入场；2026-02-09收盘确认、02-10开盘买入，04-09收盘确认、04-10开盘退出；06月保持空仓，07-15收盘确认、07-16开盘买入，08-05收盘确认、08-06开盘退出。4月退出早于用户圈出的6月区间，10月入场也晚于旧版，因此不能描述成每个手工标注均已精确复现。

`kdj_21_5_dmi_weakening` 单独保留“原KDJ买入+多头衰减卖出”，用于对照此前仅在高ADX后才允许退出的局限；新默认的准备、转多确认和弱趋势退出在其中均未启用。

### 保留的独立退出对照

适配器 `backtest/research_kdj_trend_exit.py` 只生成条件，通过已有 `reversal_signals` 和 `run_candidate` 进入统一模拟器；依赖真实OHLC、已有Wilder DMI与KDJ实现。参数全部来自配置，预热由适配器校验函数声明；仅使用当日及过去数据，不回填拐点、不维护另一套持仓。以下为保留对照配置的买入和退出定义，新默认使用上文的30日准备及转多确认。

- **买入**：21日RSV，K、D各按 `alpha=1/5` 平滑；近5日某日K、D同时≤20，近3日出现金叉，当日K>D且收盘高于昨日。没有KDJ高位卖出阈值，新适配器传入 `overbought` 会显式报错。
- **DMI退出**（`kdj_21_5_dmi`）：Wilder DMI(14)，连续2日 `-DI > +DI`。ADX仅供图表观察，不设隐含ADX门槛。
- **MA退出**（`kdj_21_5_ma60`）：连续2日收盘低于MA60，同时当日MA60低于5个观察交易日前。
- **组合退出**（`kdj_21_5_dmi_ma60`）：上述DMI与MA条件同时满足。卖出不使用KDJ，KDJ输入缺失也不会抹掉可计算的趋势退出。
- 同日入场和退出冲突仍退出优先。因此低位反转发生时如果趋势退出仍成立，入场会被挡住；这不是“只对持仓检查退出”的额外状态机。延长卖出周期并不自动提高收益。
- `kdj_trend_exit` 的 `exit_mode` 可选 `dmi` / `ma` / `dmi_and_ma` / `dmi_weakening`；`kdj_regime` 显式复用 `dmi_weakening` 并增加上述确认/失败分支。`exit_require_falling` 控制旧MA分支的斜率门槛；`entry_*` / `weak_exit_*` 分别控制新规则的入场确认和弱趋势退出。量能过滤和额外固定止损未在新配置中启用。

旧配置 `kdj_21_5` 保留此前参数：21 日 RSV，K、D 都使用 `alpha=1/5` 的递推平滑，超卖/超买为 20/80；等价参数描述是 KDJ(21,5,5) 配阈值20/80。它是用户指定的观察配置，不是冻结选参胜出者。

- 买入条件：近5个观察交易日某日 K、D 同时不高于20；近3日出现金叉；当前 K>D，且连续信号口径收盘高于昨日。卖出条件同时成立时退出优先。
- KDJ退出：近5日某日 K、D 同时不低于80，当前死叉。
- 趋势退出：近10日曾站上MA10，连续2日收盘低于MA10，且MA10下降。两种退出条件满足任一种即可。
- 成交量在这个配置中不参与过滤。风险控制沿用基础执行配置，默认没有额外固定止损或移动止盈；不能把MA退出说成最大回撤保证。

可选 `kdj_21_5_filtered` 接入已存在的过滤适配器：保留低位KDJ确认，入场还要求MA20>MA60、MA60较5日前上升、价格不低于MA60的98%，近3日有量比至少0.8的记录。量比基线为当日之前20日平均成交量。退出为高位死叉或连续2日低于下降的MA10。这个适配器的MA退出没有“近10日曾站上”的前置条件，区别显式保留，不把两者当作同一个算法。

**过滤越多不代表越好**：2020-01-02至2026-10-29的现有缓存回放中，过滤配置对512890没有成交。它用于比较过滤影响；不能把空仓零回撤描述为稳定盈利。

## 输出语义

|状态|含义|
|---|---|
|`buy`|模型空仓，已满足入场条件；不等于已经成交|
|`sell`|模型持仓，已满足技术退出条件|
|`hold`|模型持仓，未满足退出条件|
|`weakening`|模型持仓且所选趋势条件部分转弱，完整退出条件尚未成立；仅观察|
|`setup`|模型空仓，最近到过超卖区，尚未确认入场|
|`wait`|模型空仓等待；空仓时持续满足退出条件不会反复给出卖单|
|`insufficient`|指标预热或必要输入不足|

`latest.state` 使用统一回测账本的当日收盘持仓。它不是用户真实账户；`if_flat` / `if_held` 同时给出两种实际持仓情形下的条件解释。`entry` / `exit` 保留原始条件，`reasons` 区分低位反转、旧版高位死叉、DMI偏空、多头衰减、弱趋势退出、MA退出和待确认。新增 `pdi` / `mdi` / `adx`、`dmi_peak_context`、`bullish_confirmation`、`entry_trend_confirmation`、`weak_rebound_exit` 字段；不适用的旧配置返回null，所有旧字段继续保留。只有选中的退出条件才能成为卖出理由。

信号在收盘确认，下一交易日开盘由统一模拟器尝试执行。一字板、费用、现金、冷却期等规则均继续生效。`fills` 是当天已发生的模拟成交，和当天收盘新条件属于不同时间；`next_scheduled_session` 只是参考日历中的下一交易日，不能理解为已成交日期。未找到参考日期时为 `null`，不用周一至周五猜交易日。

`history=true` 附带日状态、原价K线、映射回原价尺度的退出均线、真实账本权益/现金/应收分红和成交，供现有前端或外部客户端接入。`metrics`、`stress_metrics`、`buy_hold_metrics` 分别是相同资产、相同起止窗口的常规费用、压力费用和持续持有对照；从收益曲线计算的日胜率不能当作逐笔交易胜率。

`comparison_history` 在请求历史记录时附带持有对照和压力费用的逐日账户，和策略使用相同日期。绘图命令直接消费这些记录，输出两张PNG及可编辑文字的SVG到 `output/strategy_research/charts/`：近期K线叠加MA、KDJ买入副图、DMI副图及状态带，以及完整区间收益、回撤与仓位。新默认叠加MA10入场、MA20退出和MA60参考；DMI副图的多头衰减圆圈和弱趋势方框包括空仓条件，不代表实际成交。旧交叉配置中的ADX标明仅观察，新衰减配置中标明参与退出。`--compare-profile kdj_21_5` 在相同资金/日期/执行参数下加入旧规则收益曲线。默认近期起点为2025-01-01，可用`--display-start`调整；`--profile`、`--start`与`--end`用于选择已有配置和回放日期。图中主图空心圆是收盘信号，三角是统一模拟器的次日成交，原始研究数据仅保留本地。

## 分红、质量与证据边界

信号只向前应用当时已经发生的分红/拆分，历史数据不回写；成交使用未复权价格，登记、除息、支付和FIFO红利税仍由原现金账本处理，不把复权收益和现金分红重复相加。

既有基金/股票数据格式继续可读。新增证券可按 `config/dividend_cash_actions.json.example` 提供 `<六位代码>_cash_actions.json` 标准事件列表，放在基础配置的 `cash_actions_dir`。该标准文件存在时优先使用，必须包含该证券的全部已核验事件；不要只写补充事件，否则会覆盖旧格式的读取结果。列表可为空，但空列表本身不证明没有分红。

`quality` 同时暴露：

- `stale`：是否落后于请求日期对应的完整参考交易日历；缺少完整日历时为`null`，不冒充新鲜。
- `missing_sessions`：参考日历有而该证券没有的行情日期；可能停牌或数据缺口，保留待核对状态，不补造价格。
- `cash_actions.complete`：是否有显式公司行为核验记录覆盖数据末日。
- `data_ready`：以上条件合格、末日有成交量且指标可计算。这个字段只表示数据条件，不表示策略已验证有效。

公司行为完整性记录路径由 `action_coverage_file` 指定，格式参考 `config/dividend_action_coverage.json.example`。逐项核验原始公告、导入事件后，才可填写 `verified_through` 和来源；文件修改时间、最后一次分红日期不能代替核验。当前未自动生成这种声明。

截至本轮检查，本地两只ETF行情均截止2026-10-29；512890还有2021-10-22待核对缺日，公司行为完整性记录缺失。历史回放可用于开发和观察，当前数据不应被标成可直接用于当前交易。
